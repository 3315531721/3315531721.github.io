深度学习

用 PyTorch 对照 MLP、CNN 和自定义网络。

成果与笔记

本地 MNIST 实验中，单层卷积提取局部特征，2×2 池化把特征图从 28×28 缩成 14×14，分类层输出 10 个分数。

Python · MNIST 模型定义
def make_cnn():
    return nn.Sequential(
        nn.Conv2d(1, 8, 3, padding=1),
        nn.ReLU(),
        nn.MaxPool2d(2),
        nn.Flatten(),
        nn.Linear(8 * 14 * 14, 10),
    )
