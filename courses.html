常规课程

14 门课程。课程名链接到 GitHub 对应目录，资料需用有权限的账号查看。

数学与通识 程序设计与实验 计算机系统与数据库 人工智能与数据

数学与通识

  • 计算机导论↗

    认识计算机系统、数据表示与基本算法。

  • 线性代数↗

    从向量、矩阵运算学到线性变换与特征值。

  • 大学物理↗

    复习基本物理模型，以及量纲和数量级判断。

  • 高级英语↗

    练习技术文章精读、摘要和英文表达。

程序设计与实验

  • C 语言程序设计↗

    从基础语法进阶到数组、指针、结构体与文件。

  • C 语言程序设计实验↗

    练习编译、调试、边界测试与实验记录。

  • 数据结构与算法↗

    用复杂度比较线性表、树、图、排序与查找。

  • 移动应用开发↗

    练习 Android 页面、生命周期和组件间通信。

计算机系统与数据库

  • 数字电子技术↗

    从逻辑门入门，理解组合电路与时序电路。

  • 操作系统↗

    围绕进程、内存、并发同步和文件系统学习。

  • 数据库原理及应用 A↗

    学习关系模型、SQL、索引和事务。

人工智能与数据

  • 人工智能导论↗

    了解状态空间搜索、知识表示和机器学习基础。

  • 数据科学↗

    从数据清洗与可视化走到建模和评估。

  • 深度学习↗

    串起模型、损失函数、训练过程与验证指标。
